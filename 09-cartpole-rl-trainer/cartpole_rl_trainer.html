How it learns: the 4D continuous state (cart position, cart velocity, pole angle, pole angular velocity) is discretized into bins and stored in a Q-table. Each step the agent picks an action ε-greedily, updates Q(s,a) via the Bellman equation, and ε decays as episodes accumulate — shifting the agent from random exploration to exploiting what it has learned.
